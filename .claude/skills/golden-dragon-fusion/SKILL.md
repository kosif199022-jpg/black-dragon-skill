## Combine the capabilities for one request

Use the catalog entries according to their role. Skills provide methods; playbooks provide sequencing; commands, programs, engines and tools provide operations. Libraries contribute reusable components. Studios and MCP services need their own configured runtime. Lessons contribute checks. Analysis tools can supply read-only format, inventory and provenance evidence. An entry marked reference or needing setup can inform a decision before a runtime is available.

For each requested output, work backward from its acceptance check. Combine compatible methods into a single sequence, binding each operation to a real input and passing its observed result forward. Preserve requests that remain unsupported in the final status. Do not silently drop them when a partial workflow succeeds.

## Installation and prerequisites

The complete skill directory is portable. For Claude Code use the repository copy under .claude/skills; for Codex use .agents/skills. For another installation copy one complete golden-dragon-fusion directory into that client's supported skill location. A plain ChatGPT conversation needs the skill content and an enabled execution connection for local operations. Publishing this repository alone does not configure that connection.

The bundled runners require Python 3.11 or newer. Windows file inspection requires pefile. Video conversion requires ffmpeg and ffprobe on PATH and a destination filesystem supporting hard links.
Read references/source-snapshot.md for verified repository and installed-skill coverage. When present, references/source-methods.md adds the extended local-source scan, and references/linked-media.md for the verified upstream media project references. To rebuild the local evidence map, use Python 3.12 or later and run scripts/source_map.py REPOSITORY LOCAL_EVIDENCE_JSON BRIEF_MD. Keep local evidence paths private.

For mixed deliverables, retain one chain of evidence. For a narrated inventory reel, reconcile the spreadsheet first, freeze the verified figures, compose shots from those figures, align captions with the recorded narration, then inspect the final export. For a machine animation, establish geometry and moving-part relationships before setting camera and timing; render selected frames for inspection before exporting the full timeline. For a Windows artifact report, identify the file, retain its digest with the findings, and scope conclusions to the fields actually inspected.
For a vertical stock-count report, give scripts/request.py one inventory CSV and a new MP4 output path. The same request reconciles matched, shortage and surplus item counts and renders a three-second English scorecard. Accepts Arabic or English headers as listed in scripts/inventory_reel.py. Requires Pillow 10.1+ and the media tools.
Use python scripts/methods.py "TASK" for an offline, ranked lookup across the entire bundled catalog. An exact capability ID resolves first. Combine relevant methods with the production checks; search hits are references, never evidence that a tool executed.
For multi-domain requests, use scripts/compose.py with no arguments to list the portable recipes. Select the needed recipe IDs in dependency order and pass them together to compose.py. Carry observed outputs between compatible steps and check each acceptance condition. The composed plan is not an execution receipt.
