# maven-toon-bridge — Maven Toon جوه التنين الذهبي

**الفكرة في سطر:** المحرك محرك Maven (على جهاز صاحب الشغل، برّه المستودع)، والقرار والفحص والتسليم بتوع التنين.

## ليه مش منسوخة جوه المستودع
`rights/MAVEN-RIGHTS.txt` بيقول إن أجزاء Maven (التعليمات، طريقة السكربت العربي، الشخصيات، الديكورات، فاحص السكربت،
المكتبة، الأمثلة) **ممنوع تتنشر أو تتشارك غير من لينك Maven نفسه**، والمستودع ده عام. عشان كده:
- الـ zip بيتفك على الجهاز بس (`~/dragon-tools/maven-toon` أو `MTOON_HOME`)، و`install` بيرفض أي مكان جوه المستودع.
- الكود هنا (`scripts/mtoon.py`) كود التنين، مابيستورد ولا بينسخ سطر من Maven؛ بيشغّل `toon.py` بتاع النسخة المتثبتة.
- الفيديوهات اللي تطلع ملك صاحب الشغل، وينفع تتعمل منها فلوس (البند 2 في الحقوق).
- ماتبعتش الـ zip لحد، وماتشيلش اسم Maven من النسخة.

## الأوامر
```bash
R="python -X utf8 scripts/rd.py"
$R mtoon install maven-toon-skill.zip       # فك آمن (يرفض ../ والوصلات والحجم الغريب) + إيصال sha256
$R mtoon doctor                             # doctor بتاع Maven: skia-python وnumpy وimageio-ffmpeg
#   ناقص؟ pip install -r requirements.txt جوه النسخة — 🔒 بعد «أيوه» من صاحب الشغل (~400 MB)
$R mtoon script-eg PROJECT --seconds 20     # فحص السكربت المصري (تحت)
$R mtoon run silent PROJECT --duration 15   # كابشن بس من غير صوت
$R mtoon run words PROJECT                  # توقيت الكلمات من voice.wav (أو: $R sync words)
$R mtoon run plan PROJECT && $R mtoon run stills PROJECT
$R mtoon run render PROJECT --workers 2     # كرّر لحد DONE (قابل للاستكمال)
$R mtoon run join PROJECT && $R mtoon run check PROJECT
$R mtoon credit PROJECT                     # final.mp4 ← final_credit.mp4 بالكريدت + كارت النهاية
$R mtoon gate PROJECT/final_credit.mp4      # 1080×1920، 30 fps، H.264، صوت، faststart
$R mtoon selftest
```
مجلد المشروع **برّه** فولدر المهارة (قاعدة Maven، والأداة بترفض غير كده). الـ storyboard.json تكتبه إنت بعد ما تقرا
`references/LIBRARY.md` و`STYLE.md` في النسخة المتثبتة.

## الطريق (L2)
1. **السكربت:** صاحب الشغل مصري، فالسكربت بالمصري إلا لو طلب غير كده. الشكل: هوك ≤ 7 كلمات جملة خبرية غريبة
   (مش سؤال، مش «النهارده هحكيلكم») ← سياق ← تصعيد بـ «بس / وبعدين / وفجأة» ← قلبة «تعرف ليه؟» ← قفلة ≤ 9 كلمات
   ترجع للهوك. `script-eg` لازم يعدّي. لو فيه فويس متسجل: الكلام ثابت، ماتغيّرش حرف.
2. **سطر لكل جملة:** الديكور والإضاءة ومين بيعمل إيه — اعرضه على صاحب الشغل قبل الفويس.
3. **الحلبة:** الـ storyboard قرار ذوق ← `rd.py arena size` قبل الرندر الكامل.
4. **stills والناقد:** كل لقطة من 10 (شخصيات، تفاصيل الديكور، إضاءة، عمق، الكابشن مقري). أقل من 8 تتصلّح. 3 stills
   لصاحب الشغل قبل الرندر.
5. **رندر ← join ← check ← credit ← gate**، وبعدها `rd.py sync check` لو فيه كلام، وصفحة التحميل
   (`tools/video-page`) ومكتبة «فيديوهات الكوسف».

## اللي التنين زوّده فوق Maven
| الحاجة | ليه |
|---|---|
| `script-eg` | Maven بيفحص العراقي والفصحى؛ صاحب الشغل بيتكلم مصري. نفس الشكل الدرامي، بكلمات مصرية، وبيمسك خلط اللهجات (چ، گ، هسه، شلون، لذلك…). |
| `credit` | قاعدة صاحب الشغل (RD_RULES §4): «© Mahmoud Elkosif» طول الفيلم + «مونتاج وإخراج» و«تابعني على فيسبوك» آخر 3 ث. بـ libass عشان العربي يتوصّل صح، بخط Lalezar من النسخة نفسها، والصوت بيتنسخ بايت ببايت، ونفس عدد الفريمات. |
| `gate` | معيار التصدير (1080×1920، 30 fps، H.264 High، yuv420p، faststart). |
| `install` آمن | الأرشيف بيانات مش أوامر: مفيش مسار بيهرب، ولا وصلة، والقديمة بتتعمل zip قبل ما تتبدّل. |

## الأفكار اللي اتاخدت (بكلامنا، تنفع في أي محرك تاني عندنا)
`references/IDEAS.md` — الإضاءة = فصول القصة، الكاميرا مابتقفش، الشرح جوه الديكور مش كارت طاير، لقطة قريبة جدًا على
الحاجة المهمة في أول ثانية، الرندر قابل للاستكمال في جلسات قصيرة، ونسخة كابشن بس من غير صوت.

## حدود
- السحابة: الرندر بيحتاج skia-python (pip). في جلسة من غير نت أو من غير موافقة: اكتب السكربت والـ storyboard بس، وقول كده.
- الموسيقى: بس اللي صاحب الشغل حطها بنفسه في المشروع؛ مفيش تنزيل موسيقى. أغنية جديدة = Suno بعد «أيوه».
- ميار: مفيش وش أو صوت AI ليها. ولا تقليد لأي شخصية أو قناة أو براند موجود.
- الحقايق في السكربت لازم تبقى صح، والمصادر تحت السكربت.
