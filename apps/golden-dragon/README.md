# 🐉 التنين الذهبي

أحدث نسخة من تطبيق التنين. فيها **كل** الطائر الذهبي (والطائر الأبيض والتنين الأسود تحته)، ومعاها **عقل الانصهار**: فهرس واحد اتعمل بالهندسة العكسية لكل المهارات والبرامج والمحركات والمكتبات على الجهاز، وفوقه وصفات بتوجّه أي طلب لأحسن خلطة. بيشتغل **جنب** إخواته من غير ما يلمس حد فيهم.

- **التشغيل:** اختصار «التنين الذهبي» على سطح المكتب، وبيفتح `%USERPROFILE%\GoldenDragon\GoldenDragon.exe`.
- **البيانات:** `%APPDATA%\GoldenDragon`. أول تشغيل بينسخ إعداداتك ومحادثاتك من الطائر الذهبي، ولو مش موجودة من الأبيض، ولو مش موجودة من التنين. ده نسخ مش نقل.
- **تقرير التحليل الكامل:** `تقرير-التحليل.md`.

## إزاي اتعمل
```
python -X utf8 forge\scan_skills.py         # مسح ثابت للمهارات -> forge\data\skills.json
python -X utf8 forge\build_fusion.py        # الفهرس + الوصفات + الدروس -> forge\data\fusion (بيرفض أي معرّف مش موجود)
python -X utf8 forge\make_icon.py           # الأيقونة من red-dragon.ico
python -X utf8 forge\make_golden_dragon.py  # يولّد app\ (ضيف --seed لو عايز تنسخ البيانات من دلوقتي)
python -X utf8 forge\make_test_runner.py    # tests\run_tests.ps1
powershell -ExecutionPolicy Bypass -File app\build.ps1   # الاختبارات الأول، وبعدين GoldenDragon.exe والاختصار
python -X utf8 forge\eval_fresh.py --split test   # قياس التوجيه على طلباتك الحقيقية المخفية (و--set old --split all للمجموعة التانية)
python -X utf8 forge\verify_bundle.py             # يتأكد من الـ exe المتثبّت من غير ما يشغّله
```
- `make_golden_dragon.py` بيحمّل مصنع الطائر الذهبي (اللي بيحمّل مصنع الطائر الأبيض)، ويعيد خط إنتاجه كله، وبعدين يحط طبقة التنين. فأي تصليح فوق بيوصل للتنين مع التوليد الجاي.
- ماتعدّلش في `app\` بإيدك، لأن السكربت بيرفض يكتب فوق أي تعديل يدوي. أماكن التعديل الدايم:
  - `forge\recipes.py`: الوصفات.
  - `forge\modules\dragon_fusion.py`: الموجّه والفهرس.
  - `forge\overlay\`: التصميم والأيقونة.
  - `forge\make_golden_dragon.py`: الهوية والتعليمات والأداة.
- الاختبارات في `tests\`: 45 اختبار وأكتر، من غير نت ولا مفتاح API، ومن غير تشغيل أي برنامج. منهم حد أدنى للتوجيه على الطلبات الحقيقية المخفية: top1 لازم يفضل 0.40 أو أكتر، وtop3 لازم يفضل 0.64 أو أكتر. **ارفع الحد لو نسخة طلعت أحسن، وماتنزّلوش عشان نسخة تعدّي.**

## حدود معروفة
- **إضافة كروم لازم تتثبّت مرة واحدة**، لأن مفيش إضافة من إضافات الطيور والتنانين محمّلة في كروم دلوقتي:
  1. من إعدادات التطبيق دوس «انسخ الإضافة»، والفولدر هيطلع على سطح المكتب وجواه كود الربط.
  2. افتح `chrome://extensions`.
  3. فعّل «وضع المطوّر».
  4. اختار «تحميل غير مضغوط» على الفولدر ده.
- **التوجيه:** على 112 طلب حقيقي مخفي، الأولى صح 44%، وفي أول 3 بنسبة 68%. وراوتر التنين الأحمر 59%، بس هو بيشوف سياق المحادثة. فالاتنين بيشتغلوا مع بعض: التعليمات بتقول للموديل يكتب الطلب كامل في `route`، ولو الثقة ضعيفة ياخد خطة التنين الأحمر.
- **الفهرس صورة وقت البناء:** المهارات اللي تتضاف بعد كده بتبان في `doctor`، وبتدخل الفهرس لما تشغّل `scan_skills.py` و`build_fusion.py` وتبني تاني.
- **برامج الاستوديو** بتتفك في `%USERPROFILE%\GoldenDragon\studio`، منفصلة عن الطائر الذهبي، فاللي اتفك هناك لازم يتفك تاني.

## الجديد في v3.5.0: 🔭 كل اللي على الجهاز
| الأمر | بيعمل إيه |
|---|---|
| `fusion discover` | يلف على سطح المكتب وجواه، والتنزيلات، والمستندات، وقايمة ابدأ، و`~/.claude/skills` و`~/.claude/plugins`، وإعدادات MCP، ويضيف اللي لقاه للفهرس كأنواع `pc-*` (مهارة، إضافة Claude، خادم MCP، برنامج أو اختصار، سكربت، فولدر أداة، مستودع، أرشيف مهارة). |
| `fusion local [KIND]` | يعرض الكتالوج ده. و`find "..." --kind pc` يدوّر فيه بس. |
| `fusion doctor` | فيه سطر «كتالوج الجهاز»: العدد، وإمتى اتعمل، ولو قديم يقولك `discover`. |

- **الإعدادات على الجهاز بس:** `%APPDATA%\GoldenDragon\discover.json` (أول `discover` بيعمله فاضي). فيه `roots` (فولدرات زيادة بعمقها، مثلًا `{"path": "%OneDrive%\\Desktop\\Tools", "depth": 4, "label": "tools", "archives": true}`)، و`exclude` (أنماط فولدرات ماتتلفّش)، و`use_defaults`، و`max_age_days`. والنتيجة في `local_units.json` جنبه. ولا حاجة من دول بتدخل المستودع.
- **قراية بس:** بيقرا أول كام KB من السكربتات والـ README وSKILL.md، وفهرس الأرشيفات، ومابيشغّلش حاجة. خوادم MCP بالاسم بس، من غير arguments ولا env.
- `GOLDEN_NO_LOCAL=1` يقفله، و`GOLDEN_LOCAL_HOME` يغيّر مكان ملفاته (الاختبارات بتستخدمه).
